---
name: dunnlab-check
description: Verify that the dunnlab_code plugin is loaded and list available skills
---

Confirm that the dunnlab_code plugin is loaded and working. Do the following:

1. Print: "Dunn Lab Code plugin is active."
2. List the available skills from this plugin by reading the `skills/` directory and printing each skill's name and description from its SKILL.md frontmatter.
3. Print: "You're all set! Run /dunnlab-check any time to verify your setup."
